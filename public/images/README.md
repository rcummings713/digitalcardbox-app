`company-logo.png` is an AI-edited derivative of the founder-supplied `IMG_8033.heic`, with the main lettering updated to **TheDigitalCardBox**. The original HEIC source is preserved. See [the edit prompt and provenance](../../docs/reference/branding/logo-edit.md). The shared header and compact footer show the updated artwork in a CSS viewport that excludes the outer screenshot frame. The original bitmap, symbol, lettering and tagline are retained. The browser-tab icon is a simplified SVG rendition of its envelope-and-box symbol. The updated wordmark, envelope-and-box motif, and embedded tagline appear in the displayed bitmap.
